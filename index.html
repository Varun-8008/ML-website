03 HOW IT WORKS

A tiny model.
A clear lesson.

This demo uses a basic k-nearest neighbors classifier. It finds the three example students whose weekly hours are closest to the value entered and chooses the most common group among them.

!

Hours alone don't define achievement.

The example labels are illustrative, not real student records. Actual academic performance depends on many factors, and this demo should not be used to evaluate real students.
